---
title: "skills"
description: "Upload and manage platform-stored skills."
---

`skills()` returns the skills client. An uploaded skill is referenced from a job as `upload:<id>` or `name:<skill-name>`.

## upload

<Tabs>
  <Tab title="TypeScript">
    ```ts
    upload(directory: string, options?: { org?: string }): Promise<SkillUpload[]>
    ```

    Upload a skill folder. Its name becomes your moving name pointer. The record belongs to you and to an organization (`org`, a slug or id; omitted, the client's `org` default, else your personal one): its members may reference it from their own jobs, and only you can delete it.

    ```ts
    const [skill] = await skills().upload("./my-skill", { org: "acme" });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    async def upload(directory: str, *, org: Optional[str] = None) -> List[SkillUpload]
    ```

    Upload a skill folder. Its name becomes your moving name pointer. The record belongs to you and to an organization (`org`, a slug or id; omitted, the client's `org` default, else your personal one): its members may reference it from their own jobs, and only you can delete it.

## list, get, delete

<Tabs>
  <Tab title="TypeScript">
    ```ts
    list(options?: { scope?: "my" | "shared" | "org"; limit?: number; cursor?: string }): SkillUploadList
    get(id: string): Promise<SkillUpload & { skill_md: string | null }>
    delete(id: string): Promise<void>
    ```

    Uploads, one upload with its `SKILL.md`, or delete one. `scope` is the lists' own vocabulary: `"my"` (yours, the default), `"shared"` (your organizations' other members') or `"org"` (everything in your organizations, yours included). A skill a running job references cannot be deleted, and deleting stays with the owner.

    ```ts
    const one = await skills().get(skill.id);
    ```
  </Tab>
  <Tab title="Python">
    ```python
    def list(
        *,
        scope: Optional[Literal['my', 'shared', 'org']] = None,
        limit: Optional[int] = None,
        cursor: Optional[str] = None,
    )
    async def get(skill_id: str) -> SkillUpload
    async def delete(skill_id: str) -> None
    ```

    Your uploads, one upload, or delete one. A skill a running job references cannot be deleted.

    ```python
    one = await skills().get(skill.id)
    ```
  </Tab>
</Tabs>
