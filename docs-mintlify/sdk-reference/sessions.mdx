---
title: "sessions"
description: "Read the sessions your own agents ran through the SDK."
---

`sessions()` returns the sessions client. It has its own config.

<Tabs>
  <Tab title="TypeScript">
    ```ts
    import { sessions } from "@evolvingmachines/sdk";

    interface SessionsConfig {
      apiKey?: string;        // default: process.env.EVOLVE_API_KEY
      dashboardUrl?: string;  // default: the Evolve dashboard
    }

    function sessions(config?: SessionsConfig): SessionsClient
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from evolve import sessions, SessionsConfig

    @dataclass
    class SessionsConfig:
        api_key: Optional[str] = None        # default: EVOLVE_API_KEY
        dashboard_url: Optional[str] = None  # default: the Evolve dashboard

    def sessions(config: Optional[SessionsConfig] = None) -> SessionsClient
    ```
  </Tab>
</Tabs>

## events, transcript, download

<Tabs>
  <Tab title="TypeScript">
    ```ts
    events(id: string, options?: { since?: number }): Promise<SessionEvent[]>
    transcript(id: string, options?: { since?: number }): Promise<SessionTranscript>
    download(id: string, options?: { to?: string }): Promise<string>
    ```

    The parsed events after `since`, the transcript with the session and the gateway's per-call records, or the raw JSONL trace saved to a file (returns its path).

    ```ts
    const path = await sessions().download(session.id, { to: "./traces" });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    async def events(id: str, *, since: Optional[int] = None) -> List[SessionEvent]
    async def transcript(id: str, *, since: Optional[int] = None) -> SessionTranscript
    async def download(id: str, *, to: Optional[str] = None) -> str
    ```

    The parsed events after `since`, the transcript with the session and the gateway's per-call records, or the raw JSONL trace saved to a file (returns its path).

    ```python
    path = await sessions().download(session.id, to="./traces")
    ```
  </Tab>
</Tabs>
