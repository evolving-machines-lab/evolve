---
title: "datasets"
description: "The catalog: list, read, publish, download, activate, delete."
---

`datasets()` returns the catalog client. A `ref` is `name` or `name@version`.

## list, get, getActive

<Tabs>
  <Tab title="TypeScript">
    ```ts
    list(options?: { search?: string; limit?: number; cursor?: string }): DatasetList
    get(ref: string, options?: { limit?: number; cursor?: string }): Promise<Dataset>
    getActive(name: string, options?: { limit?: number; cursor?: string }): Promise<ActiveDataset>
    ```

    The catalog, one dataset with one page of its tasks, or the active version alone. `getActive` throws `NoActiveVersionError` when nothing is runnable.

    ```ts
    const dataset = await datasets().get("terminal-bench-4@4.0");
    ```
  </Tab>
  <Tab title="Python">
    ```python
    def list(*, search: Optional[str] = None, limit: Optional[int] = None, cursor: Optional[str] = None)
    async def get(ref: str, *, limit: Optional[int] = None, cursor: Optional[str] = None) -> Dataset
    async def get_active(name: str, *, limit: Optional[int] = None, cursor: Optional[str] = None) -> ActiveDataset
    ```

    The catalog, one dataset with one page of its tasks, or the active version alone. `get_active` raises `NoActiveVersionError` when nothing is runnable.

    ```python
    dataset = await datasets().get("terminal-bench-4@4.0")
    ```
  </Tab>
</Tabs>

## publish

<Tabs>
  <Tab title="TypeScript">
    ```ts
    publish(input: { source: DatasetSource; name?: string; version?: string }, options?: { onUploadProgress?: (sentBytes: number, totalBytes: number) => void; onRegistered?: (importId: string) => void }): Promise<DatasetImport>
    ```

    Publish a version. `source` is `{ git_url, git_ref, git_path? }`, `{ directory }`, `{ archive_url }` or `{ hub_package }`. Returns the import record; follow it with `watchImport`.

    ```ts
    const imp = await datasets().publish({ source: { directory: "./my-swe" }, name: "my-swe", version: "1.0" });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    async def publish(*, git_url=None, git_ref=None, git_path=None, directory=None, archive_url=None, hub_package=None, name=None, version=None, on_upload_progress=None, on_registered=None) -> DatasetImport
    ```

    Publish a version from one source: `git_url` with `git_ref` (and `git_path`), `directory`, `archive_url`, or `hub_package`. Returns the import record; follow it with `watch_import`.

    ```python
    imp = await datasets().publish(directory="./my-swe", name="my-swe", version="1.0")
    ```
  </Tab>
</Tabs>

## getImport, watchImport, listImports

<Tabs>
  <Tab title="TypeScript">

## activate, update, delete

<Tabs>
  <Tab title="TypeScript">

    activate(name: string, version: string): Promise<Dataset>
    update(name: string, patch: { upstream_auto_import: boolean }): Promise<Dataset>

    Make a READY version the active one, switch automatic import of new upstream versions, or delete a dataset you own.
