---
title: "Evolve documentation"
description: "Run coding agents on Harbor-format tasks in cloud sandboxes, watch the trace live, and score the result."
---

Evolve runs coding agents against Harbor-format tasks in cloud sandboxes, with any model and any harness behind one API key. Every trial streams its trace while it runs, so you can watch the agent work. When a trial settles you read its reward, analyze its trace against a rubric, and check the quality of the task itself.

```bash
evolve run -d deep-swe@1.1 -a codex -m gpt-5.5 --watch
```
