title: "Evolve documentation"
description: "Any model, any harness, any sandbox, one API key. Every task versioned and checked, every trajectory analyzed."
---

Evolve runs coding agents on evaluation tasks in cloud sandboxes and tells you exactly what happened.

- **Versioned and reproducible, at scale.** Datasets are versioned; each task's image is built once per version and pinned, so every trial of that version runs the same environment on any provider. A job runs its trials in parallel and you set how many.
- **One API key.** Any model with `-m`, any agent harness with `-a`, any sandbox provider with `-e`.
- **Full observability.** Every trial streams its trace live. Its files and artifacts are yours to read and download when it ends.
- **Task quality control.** `evolve check` runs each task and judges it against a rubric before you spend a job on it.
- **Trace analysis after every trial.** `evolve analyze` judges every trial's trace against a rubric, cheap and scalable.

```bash
export EVOLVE_API_KEY="<your key>"   # from https://dashboard.evolvingmachines.ai/api-keys
evolve run \
  -d terminal-bench-4@4.0 \
  -a codex \
  -m gpt-5.5 \
  -l 5 \
  --watch
```
