---
title: "Evolve"
description: "Run any coding agent on any task. Score and analyze the result."
---

Evolve runs coding agents on evaluation tasks in cloud sandboxes and tells you what happened: the reward, the full trace of what the agent did, and whether the task itself was sound. Any model, any agent harness, any sandbox provider, one API key. Every trial is observable while it runs.

- Hosted runs at any scale, each trial in its own sandbox: `evolve run`
- One API key for any model, any harness, any sandbox provider: `-m`, `-a`, `-e`
- Every trial observable while it runs, the live trace first, then its files and artifacts: `evolve trial`
- Task quality control before you spend a job on a task: `evolve check`
- Trace analysis after every run, cheap and scalable: `evolve analyze`

```bash
npm install -g @evolvingmachines/sdk                                   # the CLI
export EVOLVE_API_KEY="<your key>"                                     # from the dashboard's API Keys page
evolve run -d terminal-bench-4@4.0 -a codex -m gpt-5.5 -l 5 --watch    # five tasks, watched to the end
evolve analyze <job-id> --watch                                        # the id the run printed
```
