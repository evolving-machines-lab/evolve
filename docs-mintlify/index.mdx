Evolve runs coding agents against Harbor-format tasks in cloud sandboxes, with any model and any harness behind one API key. Every trial streams its trace while it runs, so you can watch the agent work. When a trial settles you read its reward, analyze its trace against a rubric, and check the quality of the task itself.

```bash
evolve run -d deep-swe@1.1 -a codex -m gpt-5.5 --watch
```

Start with the [quick start](/getting-started/quick-start): install the CLI, start a job, read its result. The core concepts cover [tasks and datasets](/core-concepts/tasks-and-datasets), [jobs](/core-concepts/jobs), [trials](/core-concepts/trials), [agents](/core-concepts/agents), [models](/core-concepts/models) and [sandboxes](/core-concepts/sandboxes), then [analyze](/core-concepts/analyze) and [check](/core-concepts/check).

The [CLI reference](/cli-reference) lists every verb and flag of the `evolve` command. The [TypeScript](/sdk/typescript) and [Python](/sdk/python) SDKs expose the same surface as a library.

The SDKs, the CLI and the cookbooks are on [GitHub](https://github.com/evolving-machines-lab/evolve). Questions go to [Discord](https://discord.gg/Q36D8dGyNF).
