title: "Evolve documentation"
description: "Any model, any harness, any sandbox, one API key. Every task checked, every trajectory analyzed."
---

Evolve runs coding agents on evaluation tasks in cloud sandboxes, with any model, any agent harness and any sandbox provider behind one API key. Every trial is fully observable: its trace streams live while the agent works, and its files and artifacts are there to inspect when it ends. Task quality control is automated with `evolve check`. Trace analysis runs after every trial, cheap and scalable, with `evolve analyze`.

- **Hosted rollouts.** Every task runs in its own sandbox, reproducibly, across models, harnesses and sandbox providers.
- **One API key.** Any model with `-m`, any agent harness with `-a`, any sandbox provider with `-e`.
- **Full observability.** Every trial streams its trace live. Its artifacts and files are yours to read and download.
- **Task quality control.** `evolve check` runs each task and judges it against a rubric before you spend a job on it.
- **Trace analysis after every run.** `evolve analyze` judges every trial's trace against a rubric.

```bash
export EVOLVE_API_KEY="<your key>"   # from https://dashboard.evolvingmachines.ai/api-keys
evolve run \
  -d terminal-bench-4@4.0 \
  -a codex \
  -m gpt-5.5 \
  -l 5 \
  --watch
```
