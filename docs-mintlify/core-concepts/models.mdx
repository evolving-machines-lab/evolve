`-m` names the model an arm runs, as the harness knows it. One `EVOLVE_API_KEY` covers every provider: you never configure a provider key for a job, and every model call a trial makes is metered against the trial's spend cap.

```bash
evolve run -d deep-swe@1.1 -a claude -m fable --watch
evolve run -d deep-swe@1.1 -a codex -m gpt-5.5 -m gpt-5.6-terra --watch
```

`-m` repeats. Each model is one arm, so the second command runs every task twice, once per model. Every arm must name a model; there is no default.

## Reasoning effort

`--effort <value>` sets the reasoning effort for every arm. The accepted values are published in the capability document. `gemini` accepts no effort value, `qwen` switches thinking on or off rather than taking a level, and the other five harnesses take a level. An effort a harness cannot honor is refused when the job is created, never silently skipped.

## The analyzer's and the checker's model

The analyzer and the checker run on the `claude` roster. Their default model is `openrouter/deepseek/deepseek-v4.1-flash`; `-m` on `evolve analyze` and `evolve check`, and `--analyze-model` on `evolve run`, pick another.

The seven harnesses, and how to bring your own, are on the [agents](/core-concepts/agents) page.
