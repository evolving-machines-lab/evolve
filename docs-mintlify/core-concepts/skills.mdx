---
title: "Skills"
description: "Mount skills into every run."
---

A skill is a folder of instructions mounted into the agent's run. Give a job one or more with `--skills`; every arm gets them.

```bash
evolve run -d terminal-bench-4@4.0 -a claude -m fable --skills skills.sh/acme/skills/pdf --watch
```

`--skills` (also spelled `--skill`) repeats, and accepts:

- `skills.sh/<owner>/<repo>[/<skill>]`
- `org/repo[@ref]`
- an https git URL
- `upload:<id>`, a skill you uploaded
- `name:<skill-name>`, your moving name pointer, resolved on the server to its current upload
- a local folder, which is uploaded first and then referenced

## Upload a skill

```bash
evolve skill upload ./my-skill
evolve skill list
evolve skill show name:my-skill
evolve skill delete <id>
```

The folder's name becomes your moving name pointer: `name:my-skill` resolves to the latest upload with that name. `skill show` prints the metadata and the `SKILL.md`. A skill that a running job references cannot be deleted, and past jobs keep the version they ran with.

Every flag is in the [skill reference](/cli-reference/skill).
