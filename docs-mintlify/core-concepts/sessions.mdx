---
title: "Sessions"
description: "Managed-agent sessions: the runs the SDK recorded, read back from the CLI."
---

A session is one run of an agent through the SDK's `run()`, recorded to the dashboard. The CLI reads sessions back; it does not start them.

```bash
evolve session list
evolve session list --state ended --tag-prefix qa- -q
evolve session show <session-id>
```

`--state live` keeps only running sessions and `--state ended` only finished ones. `--agent <name>` keeps one harness, `--tag-prefix <prefix>` the sessions whose tag starts with the prefix. `session show` prints one session in full.
