---
title: "evolve trial"
description: "Inspect, download, and act on single trials."
---

```bash
evolve trial <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## trial show

```bash
evolve trial show <trial-id>
```

Show one trial in full detail.

## trial trace

```bash
evolve trial trace <trial-id> [options]
```

Print a trial's parsed trace, filtered server-side.

- `--type <event-type>`: Only events of exactly this type.
- `--grep <pattern>`: Only events matching this case-insensitive regex over type and content. A plain string is a plain substring.
- `--tail <n>`: Only the last N matching events.
- `--cursor <seq>`: Resume after this sequence number.
- `-l, --limit <n>`: Events per page fetch. Default 200, max 1000.

```bash
evolve trial trace d1a10c4e-… --grep 'permission denied' --tail 50
```

## trial download

```bash
evolve trial download <trial-id> [options]
```

Save a trial as Harbor's trial tree plus `evolve.json`, or stream one artifact to stdout. The two modes are exclusive.

- `-o, --output-dir <dir>`: Directory to save under. Default `trials/`. Files land in `<dir>/<trial-id>/`.
- `--overwrite`: Replace an existing `<dir>/<trial-id>/`.
- `--stream <artifact>`: Print one artifact to stdout instead of saving: `trace-parsed`, `verifier`, `trace-stdout`, `trace-stderr`, `trace-atif` (the ATIF trajectory), `trajectory` (reserved: the harness-native session file) or `agent-home`.
- `--cursor <seq>`: With `--stream trace-parsed`: resume after this sequence number.
- `--limit <n>`: With `--stream trace-parsed`: max events per page.

```bash
evolve trial download d1a10c4e-… --stream trace-stdout
```

## trial retry

```bash
evolve trial retry <trial-id>
```

Run one settled trial again. The result is a job.

## trial regrade

```bash
evolve trial regrade <trial-id>
```

Verifier-only re-run of one trial. The result is a job.

## trial stop

```bash
evolve trial stop <trial-id> [trial-id...]
```

Stop in-flight trials without cancelling their job.
