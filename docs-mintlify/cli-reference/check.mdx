---
title: "evolve check"
description: "Check task quality against a rubric, and read checks back."
---

```bash
evolve check [<path>] [options]
```

Check task quality against a rubric, Harbor's `harbor check`, server-side. Add `--watch` to follow. `<path>` is one task directory or a directory of task directories; `-d` names a published dataset instead. One or the other, not both.

```bash
evolve check ./tasks -i 'abs-*' -l 5 --watch
```

## Options

- `-d, --dataset <name[@version]>`: Check a published dataset's tasks instead of a local path. The checker reads the version's retained task package, and the job page's CHECK tab lists these checks by task.
- `-m, --model <name>`: Model the checker runs. Default `openrouter/deepseek/deepseek-v4.1-flash`; `fireworks/deepseek-v4.1-flash` is the same model on its Fireworks route. Must be on the `claude` roster.
- `--effort <value>`: Reasoning effort the checker runs at. Defaults to the per-model default.
- `-r, --rubric <path>`: Rubric file: TOML, YAML or JSON in Harbor's `{criteria: [{name, description, guidance}]}` shape. Defaults to the platform's check rubric, eleven criteria.
- `-p, --prompt <path>`: Prompt file for the evaluator agent, Harbor's `-p/--prompt`. Its text replaces the built-in check prompt, with `{task_path}`, `{file_tree}` and `{criteria_guidance}` rendered. Defaults to the built-in prompt.
- `-e, --env <provider>`: Sandbox provider the checker runs on. Defaults to the platform's analysis default.
- `-n, --n-concurrent <n>`: Max concurrent task checks, beneath the organization's ceiling. Defaults to the ceiling.
- `-i, --include-task-name <glob>`: Only check tasks matching the glob. Repeatable.
- `-x, --exclude-task-name <glob>`: Skip tasks matching the glob. Repeatable.
- `-l, --n-tasks <n>`: Max tasks to check, after the globs, in sorted directory order.
- `--watch`: Poll until every task check settles: 2 seconds between reads, backing off to 30 seconds while nothing changes.
- `-q, --quiet`: With `--watch`: suppress the progress lines and print the final report only.

Every command also takes the [global options](/cli-reference#global-options).

## Reading checks back

The same word, followed by `list`, `show`, `trace` or `download`, reads checks back. A task directory literally named like one of these verbs is written `./list`.

### check list

```bash
evolve check list [options]
```

List your task quality checks, newest first. Takes the [listing flags](/cli-reference#listing-flags), plus:

- `--scope <my|shared>`: Visibility scope: `my`, what you created (the default), or `shared`, your organizations' rows that teammates created.
- `--status <s1,s2,...>`: Filter by check status: `queued`, `running`, `completed`.

```bash
evolve check list --status running
```

### check show

```bash
evolve check show <check-id>
```

Show one task quality check in full, Harbor's check report, with one result per task.

### check trace

```bash
evolve check trace <task-check-id> [options]
```

Print the checker's own parsed transcript for one task check.

- `--since <n>`: Skip the first N events. To resume, pass the count you already hold.

### check download

```bash
evolve check download <check-id | task-check-id> [options]
```

Save a check as Harbor's check job folder (`check_report.json` plus one folder per task) by its check id, one task check's folder by its task check id, or stream one task check's artifact.

- `-o, --output-dir <dir>`: Directory to save under. Default `checks/`. A check id lands in `<dir>/check-<id>/`, a task check id in `<dir>/check-<task>__<7 chars>/`, Harbor's own trial name.
- `--overwrite`: Replace an existing folder of the same name.
- `--stream <artifact>`: Print one artifact of a task check to stdout instead of saving: `task-check` (the result document), `trace-parsed`, `trace-stdout`, `trace-stderr` or `agent-home`.
- `--since <n>`: With `--stream trace-parsed`: skip the first N events.

```bash
evolve check download 3f9a1c2e-… -o checks/
```
