```bash
evolve <command> [options]
```

The `evolve` command starts jobs and reads everything back. Every verb accepts `--json` for machine-readable output, and `-h` or `--help` prints its flags and one example.

## Verbs

| Verb | What it does |
| --- | --- |
| [`run`](/cli-reference/run) | Start a job. Add `--watch` to follow it. The short form of `job start`. |
| [`analyze`](/cli-reference/analyze) | Analyze a finished job's trial traces against a rubric. |
| [`check`](/cli-reference/check) | Check task quality against a rubric. |
| [`upload`](/cli-reference/upload) | Upload a Harbor job directory as a finished job. |

## Global options

These work on every command.

- `--json`: Machine-readable JSON output.
- `--api-key <key>`: API key. Defaults to `$EVOLVE_API_KEY`.
- `--base-url <url>`: API base URL. Defaults to the Evolve dashboard API.
- `-v, --version`: Print the CLI version.

## Listing flags

Every `list` command, and `job trials`, `job tasks` and `job imports`, share one set of paging and formatting flags.

- `-l, --limit <n>`: Page size.
- `--cursor <c>`: Resume from a page cursor.
- `--columns <keys|all|help>`: Choose and order columns, comma-separated. `help` lists the keys.
- `-q, --quiet`: Print only ids, one per line, for piping.
- `--no-trunc`: Full cell content instead of one-line truncation.
- `--no-headers`: Omit the header row in piped (TSV) output.
