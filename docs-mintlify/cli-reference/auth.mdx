---
title: "evolve auth"
description: "Identity, API keys, organizations."
---

```bash
evolve auth <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## auth status

```bash
evolve auth status
```

Who am I: the caller and the API key in use.

## auth org list

```bash
evolve auth org list [options]
```

List the organizations you belong to.

- `--search <text>`: Free-text filter over slug, display name and role.
- `--columns <keys|all|help>`: Choose and order columns, comma-separated. `help` lists the keys.
- `-q, --quiet`: Print only slugs, one per line, for piping.
- `--no-trunc`: Full cell content instead of one-line truncation.
- `--no-headers`: Omit the header row in piped (TSV) output.

## auth org show

```bash
evolve auth org show <slug>
```

Show one organization: your role, its members, its quota and live usage.

```bash
evolve auth org show acme
```
