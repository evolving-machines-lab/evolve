---
title: "evolve secrets"
description: "Store and manage env secrets."
---

```bash
evolve secrets <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## secrets set

```bash
evolve secrets set <NAME> [options]
```

Store an env secret, or re-shape its delivery or scoping by restating the same value. A different value under an existing name and label is refused (`secret_exists`, 409): delete first, or use another label. Never a silent overwrite.

- `--value <value>`: The secret value. Omit it to pipe the value on stdin, which keeps it out of shell history.
- `--label <label>`: Labeled-row identity. Several values of one name live side by side. Default `default`.
- `--delivery <mode>`: Required. `brokered`: the value never enters a sandbox, and needs the `--allowed-*` scoping. `direct`: the raw value in the sandbox env; scoping refused.
- `--allowed-host <host>`: Brokered scoping: a hostname, or a wildcard like `*.example.com`. Repeatable.
- `--allowed-path-prefix </prefix>`: Brokered scoping: an allowed URL path prefix. Repeatable.
- `--allowed-method <METHOD>`: Brokered scoping: an allowed HTTP method. Repeatable.

```bash
printf %s "$GITHUB_TOKEN" | evolve secrets set GITHUB_TOKEN --delivery brokered \
  --allowed-host api.github.com --allowed-path-prefix / --allowed-method GET
```

## secrets list

```bash
evolve secrets list [options]
```

List your env secrets. Metadata only; values never leave the server.

- `--columns <keys|all|help>`: Choose and order columns, comma-separated. `help` lists the keys.
- `-q, --quiet`: Print only `name[:label]`, one per line.
- `--no-trunc`: Full cell content instead of one-line truncation.
- `--no-headers`: Omit the header row in piped (TSV) output.

## secrets delete

```bash
evolve secrets delete <NAME> [options]
```

Delete an env secret by name. Revokes every runtime grant riding the row.

- `--label <label>`: The labeled row to delete, when several labeled rows share the name.

```bash
evolve secrets delete GITHUB_TOKEN --label staging
```
