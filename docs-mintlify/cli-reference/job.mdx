---
title: "evolve job"
description: "Start, follow, and derive jobs."
---

```bash
evolve job <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## job start

```bash
evolve job start [options]
```

Start a job; add `--watch` to follow it. Exactly the options of [`evolve run`](/cli-reference/run).

## job list

```bash
evolve job list [options]
```

List jobs, newest first: yours, or `--scope shared` for your organizations'. Takes the [listing flags](/cli-reference#listing-flags), plus:

- `--search <text>`: Free-text filter over job name and dataset names.
- `--scope <my|shared>`: Visibility scope: `my`, what you created (the default), or `shared`, your organizations' rows that teammates created.

```bash
evolve job list --limit 20 -q
```

## job show

```bash
evolve job show <id> [id...]
```

Show one or more jobs in full, including pass@k once every attempt has settled.

## job trials

```bash
evolve job trials <id> [options]
```

List a job's trials. Takes the [listing flags](/cli-reference#listing-flags), plus:

- `--status <s1,s2,...>`: Filter by trial status, for example `INFRASTRUCTURE_ERROR`.
- `--dataset <name>`: Filter to one dataset's trials.

```bash
evolve job trials 3e1f9a2c-… --status FAILED,SCORING_ERROR
```

## job tasks

```bash
evolve job tasks <id> [options]
```

Per-task rollup of a job: one row per task. Takes the [listing flags](/cli-reference#listing-flags).

## job compare

```bash
evolve job compare <id> <id> [...]
```

Compare two to ten jobs side by side.

## job cancel

```bash
evolve job cancel <id>
```

Request cancellation of a job.

## job delete

```bash
evolve job delete <id> [options]
```

Permanently delete a job you created: its trials, traces, analyses and stored files.

- `-y, --yes`: Delete without a confirmation prompt.

## job stop

```bash
evolve job stop <id> --dataset <name>
```

Stop one dataset's live trials without cancelling the job.

- `--dataset <name>`: The dataset whose live trials to stop. Required.

## job resume

```bash
evolve job resume <id> [options]
```

A new linked job over a terminal job's failed or stopped trials.

- `-f, --filter-error-type <type>`: Failure types to resume, matched on the trial's exception type. Repeatable. Defaults to the standard failure set plus stopped trials.

```bash
evolve job resume 3e1f9a2c-… -f InfrastructureError
```

## job retry

```bash
evolve job retry <id> [options]
```

A new linked job re-running selected trials: all of them, the failed ones only, or named ids.

- `--failed-only`: Only retry failed trials: `SCORING_ERROR`, `INFRASTRUCTURE_ERROR`, `BUDGET`, `INDETERMINATE`. Stopped and scored trials are not failures.
- `-t, --trial <trial-id>`: Retry exactly this trial. Repeatable, all or nothing: each must be settled, and the job may still be running. Not combinable with `--failed-only`.

## job regrade

```bash
evolve job regrade <id> [options]
```

Verifier-only re-run of a terminal job. The result is a job.

- `--status <s1,s2,...>`: Only regrade source trials in these statuses.
- `--task <name>`: Only regrade source trials of this task.

## job imports

```bash
evolve job imports [options]
```

List your job imports (uploads), newest first. This is how an import id is found again. Takes the [listing flags](/cli-reference#listing-flags), plus:

- `--status <QUEUED|RUNNING|COMPLETED|FAILED>`: Filter by import status.

## job import

```bash
evolve job import <import-id> [options]
```

Show one job import, an upload's record.

- `--watch`: Poll until the import settles: `COMPLETED`, and the job is printed, or `FAILED`.

## job download

```bash
evolve job download <id> [options]
```

Download the job's results, unpacked as the standard job-directory tree plus `evolve.json` records.

- `-o, --output-dir <dir>`: Directory to unpack into. Defaults to the current directory. The tree lands in `<dir>/job-<id>/`.
- `--overwrite`: Replace an existing `<dir>/job-<id>/`.

## job grep

```bash
evolve job grep <id> <pattern> [options]
```

Search every trial's parsed trace in one server-side pass.

- `--type <event-type>`: Only search events of exactly this type.
- `-l, --limit <n>`: Per-trial match groups per page. Default 50, max 200.
- `--cursor <c>`: Resume after this trial id, the previous page's `nextCursor`.

```bash
evolve job grep 3e1f9a2c-… 'permission denied'
```
