---
title: "evolve run"
description: "Start a job."
---

```bash
evolve run [options]
```

Start a job. `evolve run` is the short form of `evolve job start`, and both take the same options.

```bash
evolve run -d terminal-bench-4@4.0 -a codex -m gpt-5.5 -k 2 --watch
```

## What to run

- `-d, --dataset <name[@version]>`: Dataset to run. Repeatable. A bare name means the active version.
- `-i, --include-task-name <glob>`: Include filter over task names, applied to every dataset. Repeatable.
- `-x, --exclude-task-name <glob>`: Exclude filter over task names, applied to every dataset. Repeatable.
- `-l, --n-tasks <n>`: Cap the task count of each dataset after the filters.
- `-a, --agent <name[@version]>`: Agent, built-in or registered.
- `-m, --model <name>`: Model. Repeatable; each model is one arm.
- `-k, --n-attempts <n>`: Attempts per task and arm. Default 1.
- `-n, --n-concurrent <n>`: Parallel trials. Default 4.
- `-e, --env <provider>`: Sandbox provider: `e2b`, `daytona` or `modal`. Default `daytona`.
- `--job-name <name>`: User-facing label. Generated by the server when omitted.

## The arm

Each of these applies to every arm of the job.

- `--effort <value>`: Reasoning effort for every arm. The values are published in the capability document. Applied verbatim: an agent that cannot honor it is refused by the server, never silently skipped.
- `--preset <name>`: Named settings preset for every arm. `no-internet` turns the vendor's server-side web tools off; `pinned-context` fixes the context window. Applied verbatim: an agent that cannot guarantee it is refused by the server.
- `--agent-kwarg, --ak key=value`: Agent kwarg for every arm, as `key=value`. Repeatable. The delivered key is `config`: `--ak 'config=<path|inline JSON>'` becomes the harness's native settings file, with your document as the base and the platform's routing on top. The server refuses unsupported kwargs, and config keys touching billing, base URL, routing or env.
- `--skills, --skill <ref|path>`: Skill for every agent arm. Repeatable. Accepts `skills.sh/<owner>/<repo>[/<skill>]`, `org/repo[@ref]`, an https git URL, `upload:<id>`, `name:<skill-name>` (your moving name pointer, resolved server-side), or a local folder, which is uploaded first and then referenced.
- `--ae, --agent-env KEY=VALUE`: Environment for every agent run. Repeatable. A pass-through slot the server owns.
- `--ve, --verifier-env KEY=VALUE`: Environment for every verifier run. Repeatable. The server honors exactly `REWARDKIT_JUDGE` and `REWARDKIT_MODEL`, rewardkit's judge override, and refuses any other key.
- `--secret NAME[@LABEL][=ENVNAME]`: Attach one of your stored env secrets to every agent run. Repeatable. `NAME` is the stored secret's name. `@LABEL` picks a labeled row; omitted, the `default` row or the only row, and several labels with no `default` is refused as ambiguous. `=ENVNAME` renames the env var inside the sandbox. References only: the value never rides the command line or the wire.
- `--secret-inline NAME[@LABEL]:DELIVERY=VALUE`: Save `VALUE` into your vault as an env secret and attach it to this job in one step. Repeatable. `DELIVERY` is `brokered` or `direct` and sits before `=`, so everything after the first `=` is the value, byte for byte. `@LABEL` defaults to `default`. Restating an existing secret exactly attaches it, so re-running the same command converges; a different value or delivery is refused as `secret_exists`. The job stores only the reference.

## Spend and retries

- `--max-trial-spend <usd>`: Model-spend cap for each trial. Defaults to the server's, $200.
- `-r, --max-retries <n>`: Max automatic retries per trial on infrastructure errors. Defaults to the server's fleet default; `0` turns retries off. Each attempt carries the full trial cap.
- `--retry-include <exception>`: Exception types to retry on. Repeatable. Defaults to everything `--retry-exclude` admits.
- `--retry-exclude <exception>`: Exception types not to retry on. Repeatable, and it wins over `--retry-include`. Defaults to the platform's non-retryable set.

## Embedded analysis

- `--analyze`: Analyze each trial's trace server-side as it settles. Cancelled trials are skipped. Bare, it uses the platform's analyze model, rubric and prompt.
- `--analyze-model <name>`: Model the analyzer runs. Must be on the `claude` roster. Implies `--analyze`.
- `--analyze-rubric <path>`: Rubric file for the analyzer: TOML, YAML or JSON in the `{criteria}` shape. Implies `--analyze`.
- `--analyze-prompt <path>`: Prompt file for the analyzer. Replaces the built-in prompt. Implies `--analyze`.
- `--analyze-provider <provider>`: Sandbox provider the analyzer runs on. Defaults to the platform's analysis default. Implies `--analyze`.
- `--analyze-effort <value>`: Reasoning effort the analyzer runs at. Defaults to the per-model default: `high` on `openrouter/deepseek/deepseek-v4.1-flash`, `max` on `glm-5.3-flash`. Implies `--analyze`.

## Timeouts

- `--timeout-multiplier <x>`: Multiplier for task timeouts. Default 1.0; any finite number above 0. It multiplies each task's declared timeouts for this job only; the task is never rewritten. A product past the runtime's timer ceiling is refused at create.
- `--agent-timeout-multiplier <x>`: Multiplier for the agent execution timeout. Overrides `--timeout-multiplier`.
- `--verifier-timeout-multiplier <x>`: Multiplier for the verifier timeout. Overrides `--timeout-multiplier`.
- `--agent-setup-timeout-multiplier <x>`: Multiplier for the agent setup timeout. Overrides `--timeout-multiplier`.
- `--environment-build-timeout-multiplier <x>`: Multiplier for the environment build timeout. Overrides `--timeout-multiplier`.

## Config file and output

- `-c, --config <path>`: Job config file, YAML or JSON in the spec's vocabulary. Explicit flags override its fields.
- `--print-config`: Print the resolved job body as JSON and exit without running.
- `--watch`: Stream events until the job finishes.
- `-q, --quiet`: With `--watch`: suppress the event log and print the final block only.
- `-y, --yes`: Accepted for compatibility. Hosted runs have no prompt to confirm.

Every command also takes the [global options](/cli-reference#global-options).
