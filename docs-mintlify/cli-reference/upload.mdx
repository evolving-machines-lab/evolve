---
title: "evolve upload"
description: "Upload a job directory as a finished job."
---

```bash
evolve upload <job_dir> [options]
```

Upload a job directory in the Harbor job layout, its `.tar.gz`, or a public URL of one, as a terminal job. The command follows the import to the job.

```bash
evolve upload ./job-2026-08-27__12-00-00 -d terminal-bench-4@4.0
```

## Options

- `-d, --dataset <name[@version]>`: Link the uploaded trials to a published dataset version by task name.
- `--from <url>`: A public https URL of the job archive (`.tar.gz`) that the server fetches itself, instead of `<job_dir>`. No local bytes.
- `--no-wait`: Return after the import is accepted, with the import id, instead of following it to the job. Re-attach with `evolve job import <id> --watch`.

Every command also takes the [global options](/cli-reference#global-options).

## Following an import

`evolve job imports` lists your uploads, and `evolve job import <import-id> --watch` follows one. See the [`job`](/cli-reference/job) group.
