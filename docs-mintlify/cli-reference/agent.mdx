---
title: "evolve agent"
description: "Register and manage your own agents."
---

```bash
evolve agent <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## agent list

```bash
evolve agent list [options]
```

List your registered agents. Takes the [listing flags](/cli-reference#listing-flags).

## agent show

```bash
evolve agent show <name>
```

Show one registered agent.

## agent add

```bash
evolve agent add <name> [options]
```

Register an agent from an install script or a local directory.

- `--install-script <path>`: Install script file. Its contents are uploaded.
- `--dir <path>`: Local agent directory, tarred and uploaded.
- `--run <command>`: Run command, executed with `sh -c`. Required.
- `--ae, --agent-env KEY=VALUE`: Environment injected at run time. Repeatable.

```bash
evolve agent add acme-cli --install-script ./install.sh --run "acme-cli --headless"
```

## agent remove

```bash
evolve agent remove <name>
```

Delete a registered agent. Past jobs keep their record.
