title: "evolve dataset"
description: "Browse and publish the catalog."
---

```bash
evolve dataset <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## dataset list

```bash
evolve dataset list [options]
```

List the dataset catalog. Takes the [listing flags](/cli-reference#listing-flags), plus:

- `--search <text>`: Free-text filter over name and description.

## dataset show

```bash
evolve dataset show <name[@version]> [options]
```

Show one dataset: its versions, its tasks, and the providers each task can run on.

- `-l, --limit <n>`: Task-list page size.
- `--cursor <c>`: Resume the task list from a cursor.

```bash
evolve dataset show terminal-bench-4@4.0
```

## dataset check

```bash
evolve dataset check <dir>
```

Pre-flight a local corpus. A dry run: nothing is uploaded, nothing is written.

## dataset publish

```bash
evolve dataset publish [options]
```

Publish a dataset version from a git source, a local directory, or a fetchable source: a public tarball URL, or a public hub package.

- `--git <url>`: Git repository URL. With `--ref`.
- `--ref <ref>`: Pinned git ref: a full 40-hex commit sha, or a tag, resolved to its commit at publish and verified at import. Branch names are refused as `unpinned_git_ref`. With `--git`.
- `--path <subfolder>`: Repository subfolder holding the corpus. With `--git`; only that folder is imported.
- `--dir <path>`: Local corpus directory, tarred and uploaded. Pre-flighted first; see `--skip-preflight`.
- `--from <url|hub:org/name[@ref]>`: Fetchable source the server pulls itself, with no local bytes: a public https tarball URL, or `hub:org/name[@ref]`, a public Harbor hub package. The ref is the latest tag by default, a revision number, or `sha256:<digest>`; it is resolved and digest-pinned when the publish is accepted.
- `--name <dataset>`: Catalog dataset name to create or extend. Optional with `--dir` when the corpus carries a `dataset.toml` manifest, and with `--from hub:…`, which defaults to the package's short name. Required with `--git` and `--from <url>`.
- `--version <v>`: Version label for the published version. Optional with `--dir` when `dataset.toml` declares one, and with `--from hub:…`, which defaults to the resolved revision. Required with `--git` and `--from <url>`.
- `--watch`: Poll until the publish settles: the version `READY` (built and active) or `FAILED`.
- `--skip-preflight`: Upload without the pre-flight check. A refused task then lands `FAILED` at import instead of being caught here.

```bash
evolve dataset publish --from hub:cookbook/hello-world --watch
```

## dataset watch

```bash
evolve dataset watch <name | import-id>
```

Re-attach to a publish and follow it to `READY` or `FAILED`, the same follow `dataset publish --watch` renders. Works after the CLI exited, or from another machine.

## dataset download

```bash
evolve dataset download <name[@version]> [options]
```

Download the original corpus package. Owner only.

- `-o, --output-dir <dir>`: Directory to save into. Defaults to the current directory.

## dataset activate

```bash
evolve dataset activate <name> <version>
```

Make a `READY` version the dataset's active version.
