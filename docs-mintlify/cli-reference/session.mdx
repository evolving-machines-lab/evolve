---
title: "evolve session"
description: "List and inspect sessions."
---

```bash
evolve session <command> [options]
```

Every command below takes the [global options](/cli-reference#global-options).

## session list

```bash
evolve session list [options]
```

List your sessions, newest first. Takes the [listing flags](/cli-reference#listing-flags), plus:

- `--state <live|ended>`: Only live, or only ended, sessions.
- `--agent <name>`: Only sessions of this agent harness. Exact match.
- `--tag-prefix <prefix>`: Only sessions whose tag starts with this prefix.

```bash
evolve session list --state ended --tag-prefix qa- -q
```

## session show

```bash
evolve session show <session-id>
```

Show one session in full.
