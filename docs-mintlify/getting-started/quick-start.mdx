A trial is one agent's attempt at one task. A job is a set of trials: the tasks of one or more datasets, run by one or more agents. This page takes you from an empty terminal to a downloaded trial.

## Install the CLI and set your key

```bash
npm install -g @evolvingmachines/sdk
export EVOLVE_API_KEY="<your key>"
evolve auth status
```

See [installation](/getting-started/installation) for the SDKs and where the key comes from.

## Pick a dataset

The catalog lists every dataset you can run, with its versions.

```bash
evolve dataset list
evolve dataset show deep-swe@1.1
```

`dataset show` prints the version's tasks and, for each task, which sandbox providers can run it.

## Start a job and watch it

Name a dataset, an agent, and a model. `--watch` streams the job's events until it finishes. `-l 5` caps the run at five tasks, so the first job is small.

```bash
evolve run -d deep-swe@1.1 -a codex -m gpt-5.5 -l 5 --watch
```

The final block prints the job id, the status of every trial, and what the trials spent. Without `--watch` the command returns the id at once and the job keeps running.

## Read the result

```bash
evolve job show <job-id>
evolve job trials <job-id>
evolve trial show <trial-id>
```

`job show` is the whole job: every trial's status, the rewards, the spend. `job trials` lists the trials one per line with their ids. `trial show` is one trial in full, with its reward and, when it failed, why.

## Download the trial

A trial downloads as Harbor's trial tree: the trajectory, the agent's stdout and stderr, the verifier log, and the reward.

```bash
evolve trial download <trial-id> -o trials/
```

To read one artifact without saving anything, stream it instead.

```bash
evolve trial download <trial-id> --stream verifier
```
