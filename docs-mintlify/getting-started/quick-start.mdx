---
title: "Quick start"
description: "Your first job, from install to download."
---

Five steps take you from an empty terminal to a downloaded trial. A trial is one agent's attempt at one task. A job is a set of trials.

## Install the CLI and set your key

```bash
npm install -g @evolvingmachines/sdk
export EVOLVE_API_KEY="<your key>"
evolve auth status
```

The key comes from the dashboard's API Keys page at [dashboard.evolvingmachines.ai](https://dashboard.evolvingmachines.ai). `auth status` prints who the key belongs to.

## Pick a dataset

```bash
evolve dataset list
evolve dataset show terminal-bench-4@4.0
```

`dataset list` prints every dataset you can run. `dataset show` prints one version's tasks, their timeouts, and which sandbox providers can run each.

## Run a job and watch it

```bash
evolve run -d terminal-bench-4@4.0 -a codex -m gpt-5.5 -l 5 --watch
```

`-d` names the dataset and version, `-a` the agent harness, `-m` the model, and `-l 5` caps the run at five tasks. `--watch` streams every event until the job finishes, then prints the job id, how many trials landed in each status, and the spend. Without `--watch` the command prints the id and returns.

## Read the result

```bash
evolve job show <job-id>
evolve job trials <job-id>
evolve trial show <trial-id>
```

`job show` is the whole job. `job trials` lists its trials with their ids. `trial show` is one trial: its reward and, when it failed, why.

## Download a trial

```bash
evolve trial download <trial-id> -o trials/
evolve trial download <trial-id> --stream verifier
```

The first saves the trial tree: the trajectory, stdout, stderr, the verifier log, the reward. The second prints one artifact instead of saving.
