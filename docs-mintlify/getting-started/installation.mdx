## The CLI

The `evolve` command ships inside the npm package `@evolvingmachines/sdk`.

```bash
npm install -g @evolvingmachines/sdk
evolve --version
```

## The SDKs

The same surface is available as a library in TypeScript and in Python.

<Tabs>
  <Tab title="TypeScript">
    ```bash
    npm install @evolvingmachines/sdk
    ```
  </Tab>
  <Tab title="Python">
    ```bash
    pip install evolve-sdk
    ```

    Python 3.10 or newer. The hosted clients on these pages talk to the platform directly. Node.js and npm are needed only to run agents on your own machine through `run()`, which these pages do not cover.
  </Tab>
</Tabs>

## Your API key

Create an API key on the dashboard's API Keys page at [dashboard.evolvingmachines.ai](https://dashboard.evolvingmachines.ai) and export it. Every command and every SDK client reads `EVOLVE_API_KEY`.

```bash
export EVOLVE_API_KEY="<your key>"
evolve auth status
```

`auth status` prints who the key belongs to. The key itself is never printed back. For one call with a different key, pass `--api-key <key>` on the command line, or `{ apiKey }` to an SDK client.
