---
title: "agents"
description: "Register and manage your own agents."
---

`agents()` returns the registered-agents client. A registered agent's name works in a job's `agents[].name` like a built-in.

## create

<Tabs>
  <Tab title="TypeScript">
    ```ts
    create(input: { name: string; org?: string; run_command: string; env?: Record<string, string> } & ({ install_script: string } | { directory: string })): Promise<Agent>
    ```

    Register an agent from an install script's text, or from a local directory. `run_command` runs with `sh -c` at the task's working directory; what it can rely on, and the registration limit, are on [agents](/core-concepts/agents#register-your-own-agent). The registration belongs to you and to an organization (`org`, a slug or id; omitted, the client's `org` default, else your personal one): its members may name the agent in their own jobs, and only you can change or delete it. A name stays unique per person, so two teammates may each register their own `acme-cli`.

    ```ts
    const agent = await agents().create({
      name: "acme-cli",
      install_script: "curl -fsSL https://acme.dev/install.sh | sh",
      run_command: "acme-cli --headless",
    });
    ```
  </Tab>

## list, get, upsert, delete

<Tabs>
  <Tab title="TypeScript">
    ```ts
    list(options?: { scope?: "my" | "shared" | "org"; limit?: number; cursor?: string }): AgentList
    get(name: string): Promise<Agent>
    upsert(
      name: string,
      input: { run_command: string; env?: Record<string, string> } & ({ install_script: string } | { directory: string }),
    ): Promise<Agent>
    delete(name: string): Promise<void>
    ```

    Registered agents, one agent, replace one without a gap, or delete one. `scope` is the lists' own vocabulary: `"my"` (yours, the default), `"shared"` (your organizations' other members') or `"org"` (every registration in your organizations, yours included); `get` takes a name, which is yours by construction. Past jobs keep the agent they recorded. `upsert` creates when the name is free and replaces when it is not, consuming no new slot; it is a full replacement, so an omitted `env` becomes empty.

    ```ts
    await agents().upsert(
      "acme-cli",
      {
        install_script: "curl -fsSL https://acme.dev/install.sh | sh",
        run_command: "acme-cli --headless --v2",
      },
    );
    ```
  </Tab>
