## agent list

```bash
evolve agent list [options]
```

List registered agents.

<ParamField path="--scope" type="my | shared | org">
  Visibility scope: `my`, your own registrations (the default); `shared`, your organizations' other members'; or `org`, every registration in your organizations.
</ParamField>

## agent show

```bash
evolve agent show <name>
```

Show a registered agent: your own of that name first, else the oldest of that name in an organization you belong to — the one a job of that organization runs. A name outside your organizations answers `agent_not_found`.

## agent add

```bash
evolve agent add <name> [options]
```

Register an agent from an install script or a local directory.

The registration belongs to you and to an organization: its members may name the agent in their own jobs, and only you can change or delete it. A name stays unique per person, so two teammates may each register their own `acme-cli`.

A registration that cannot be built — the script exits non-zero, or installs nothing executable (see [Registered agents](/core-concepts/agents)) — fails its trials as the agent's own error (`failure_phase` `agent_source`; the trial's stderr stream holds the install's output), never retried: `agent remove` it, `agent add` it again, and resume the job.

<ParamField path="--org" type="name">
  Organization the registration belongs to. Default: the organization from `evolve auth org use`, else your personal one. It is fixed once set.
</ParamField>

<ParamField path="--install-script" type="path">
  Install script file. Its contents are uploaded.
</ParamField>

<ParamField path="--dir" type="path">
  Local agent directory, tarred and uploaded.
</ParamField>

<ParamField path="--run" type="command" required>
  Run command, executed with `sh -c`.
</ParamField>

<ParamField path="--ae, --agent-env" type="KEY=VALUE">
  Environment injected at run time. Repeatable. It may not override the six run-contract keys, and a credential-shaped key is refused, both with `agent_invalid_env`; see [the run contract](/core-concepts/agents#the-run-contract).
</ParamField>

```bash
evolve agent add acme-cli --install-script ./install.sh --run "acme-cli --headless"
```

## agent remove

```bash
evolve agent remove <name>
```

Delete a registered agent. Past jobs keep their record.
