```bash
evolve skill <command> [options]
```

## skill list

```bash
evolve skill list [options]
```

List uploaded skills, newest first.

<ParamField path="--scope" type="my | shared | org">
  Visibility scope: `my`, your own uploads (the default); `shared`, your organizations' other members'; or `org`, every upload in your organizations.
</ParamField>

<ListFlags />

## skill upload

```bash
evolve skill upload <dir> [options]
```

Upload a skill folder. Its name becomes your moving name pointer.

The record belongs to you and to an organization: its members may reference it from their own jobs, and only you can delete it.

<ParamField path="--org" type="name">
  Organization the record belongs to. Default: the organization from `evolve auth org use`, else your personal one.
</ParamField>

## skill show

```bash
evolve skill show <id | name:<skill-name>>
```

Show one uploaded skill: its metadata and its `SKILL.md`.

```bash
evolve skill show name:my-skill
```

## skill delete

```bash
evolve skill delete <id>
```

Delete an uploaded skill record. Past jobs keep their locks. Refused (`skill_in_use`, 409) while a running job references it.
