Evolve is hosted evaluation for agents: bring your own tasks or pick a public dataset, and run any model on any agent harness against them, in parallel, in cloud sandboxes. Each task is pinned to one versioned environment, so every run starts from the same place today or next month. Every trial returns its reward, its live trace, its files and its logs, with a quality verdict on any task before you spend on it and a judged analysis of any trajectory after.

- **One API key.** Any model with `-m`, any agent harness with `-a`, any sandbox provider with `-e`; no provider keys to manage.
- **Task quality control.** `evolve check` runs each task and judges it against a rubric before you spend a job on it.
- **Full observability.** Every trial streams its trace live; its files, artifacts, agent logs and verifier logs are yours to read and download when it ends.
- **Trace analysis after every trial.** `evolve analyze` judges every trial's trace against a rubric, cheap and scalable.

```bash
export EVOLVE_API_KEY="<your key>"   # from https://dashboard.evolvingmachines.ai/api-keys
evolve run \
  -d terminal-bench-4@4.0 \
  -a codex \
  -m gpt-6-astra \
  -l 5 \
  --watch
```

## The whole process

1. **Install and sign in.** `npm install -g @evolvingmachines/evolve`, then export the key from the dashboard's API keys page. [Installation](/getting-started/installation).
2. **Get tasks.** Pick a public dataset from `evolve dataset list`, or bring your own: write tasks in the Harbor format, or convert a benchmark you already have. [Tasks](/core-concepts/tasks), [Datasets](/core-concepts/datasets).
3. **Check the tasks.** `evolve check` runs each task and judges it against a rubric before you spend a job on it. [Check](/core-concepts/check).
4. **Publish.** `evolve dataset publish` makes the tasks a versioned dataset you and your team can run. [Datasets](/core-concepts/datasets).
5. **Run.** `evolve run -d <dataset> -a <agent> -m <model>`; every trial streams live. [Jobs](/core-concepts/jobs), [Quick start](/getting-started/quick-start).
6. **Read and judge.** Download any trial's tree, and `evolve analyze` judges every trace against a rubric. [Trial outputs](/core-concepts/trial-outputs), [Analyze](/core-concepts/analyze).

A coding agent does every step from the same CLI: `evolve skills install` gives it the manual, and `evolve skills get create-task`, `rewardkit`, `create-adapter` and `publish` guide steps 2 and 4. [Skills](/core-concepts/skills).
