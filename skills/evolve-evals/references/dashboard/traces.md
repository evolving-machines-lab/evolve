**Traces** lists individual runs. **Jobs** groups evaluation trials; Traces lets you inspect each run directly.

![Individual evaluation and analysis runs with models, providers, costs, and status.](/images/dashboard-traces.png)

*Run tags distinguish the evaluated agent from the reviewer.*

| Tag | Run |
| --- | --- |
| **Eval** | One evaluation trial. |
| **Regrade** | A verifier-only rerun. |
| **Analyze** | A trial-review run. |
| **Check** | A task-quality review. |
| **Agent** | A managed-agent session. |

## Choose the workspace

### Personal

**Mine** shows runs you created, including those in teams.

**Shared with me** shows teammates' runs and runs shared with your email address.

### Team

The list shows runs in that team. **Created by** identifies who started each one.

## Find and inspect a run

### 1. Search by name

Read the kind, task or session name, model, provider, status, and cost to identify the run.

### 2. Open its row

The viewer shows that run's transcript. An Analyze row opens the analyzer's work; an Eval row opens the evaluated agent's work.

### 3. Inspect or act

Read events and downloads. Stop live runs or delete finished records only where your creator permissions allow it.

Sharing lets someone inspect a run. It does not transfer ownership or grant stop/delete permission.
