---
title: "Skills for your coding agent"
description: "Two commands give Claude Code, Codex, Cursor and the others the evolve manual."
---

```bash
npm install -g @evolvingmachines/sdk
evolve skills install
```

`skills install` writes one small skill, `evolve`, into the skill folder of every coding agent it knows: Claude Code, Codex, Cursor, Copilot, Gemini CLI, OpenCode and the shared `~/.agents/skills`. It prints each path it wrote. `--target claude` names one agent; `--path <dir>` names a folder of your own.

From then on, when you mention Evolve, evals, datasets, jobs or tasks, the agent reads the manual from the command itself before it acts:

```bash
evolve skills get evals                        # the index of these docs, one line per page
evolve skills get evals core-concepts/tasks    # one page
evolve skills get create-task                  # how to write a task
```

The manual ships inside the package, so it always matches the version you installed. `evolve skills list` names everything it serves.

With the [skills CLI](https://github.com/vercel-labs/skills) instead, the same skill installs from the repository:

```bash
npx skills add evolving-machines-lab/evolve
```
